# ERIMAR MARK 7 Dify Connector — Privacy

The connector receives `goal` and optional `kind` and sends them via HTTPS with a bearer credential to the API address configured **by the installing workspace**. The connector does not itself store input text, keep a customer database or send project data to a preconfigured ERIMAR operator endpoint. Dify and the configured service may keep their own logs and set their own retention policies.

Avoid transmitting sensitive personal data, credentials, medical information or payment records. Confirm the privacy policy of the configured API owner before real customer use.
