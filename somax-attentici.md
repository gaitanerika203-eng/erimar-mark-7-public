# SOMAX / AttentiCI — public implementation

SOMAS → SOMAX → TROPIC → MCI → MCSIPIM → AttentiCI. This publicly distributed runtime only implements normalization and deduplication, allowlisted coarse measurements, and plan-only outputs. It does not attach to private telemetry, invoke MCP services, control cloud accounts or execute unapproved jobs. Health and status are verifiable via local API endpoints.

The design language is Matrix Gold: graphite/black, accessible golden accents, mobile-first UI. Reuse as a neutral visual system, not as a copy of nonpublic ERIMAR STYLE or VITRINA assets.
